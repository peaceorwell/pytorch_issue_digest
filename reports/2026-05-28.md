# PyTorch Compiler Issue Digest - 2026-05-28

## 今日概览

- 今日按标题关键词匹配到 29 条 issue（open 16，closed 13）。
- 主要风险信号是 **silent correctness**：多条 open 问题显示 `torch.compile`/Inductor 与 eager 语义不一致且可能无报错。
- 主题集中在：Inductor cache/key 语义、dynamic shape/unbacked symbol、complex dtype codegen、CUDA graph/stream 交互、Dynamo 导出与图断裂。
- 存在高优先级与潜在 silent-correctness 条目，尤其是 #185449、#185382、#185337、#185330、#185246、#185074。
- 另有一批 closed 条目由“nightly 未复现”关闭，需注意回归风险与复现漂移。

## 重点关注

- #185449 [Flash attention backend type not stored in inductor cache, causes silent usage of wrong backend](https://github.com/pytorch/pytorch/issues/185449)  
  - 关注原因: 命中 `module: correctness (silent)`，且指向跨进程共享 cache key 缺少 SDPA backend 维度，可能全局污染结果。  
  - 建议动作: 先补 cache key 设计确认（`sdpa_kernel`/`enable_*_sdp` flags），再加多进程回归测试。
- #185382 [`torch.compile`: Inductor silently produces wrong results for `addcdiv_`/`addcmul_` when `.item()` graph break occurs in a loop](https://github.com/pytorch/pytorch/issues/185382)  
  - 关注原因: 明确“silently produces wrong results”，涉及 graph break + inplace ternary op，正确性风险高。  
  - 建议动作: 先最小化 repro 并加 correctness guard；必要时短期禁用该模式组合。
- #185337 [[inductor] CPU codegen does not preserve explicit float32 to float16 to float32 cast semantics](https://github.com/pytorch/pytorch/issues/185337)  
  - 关注原因: 明确 eager 语义被破坏，且已带 `module: correctness (silent)`。  
  - 建议动作: 审核 `joint_graph.py` cast 消除路径，补精度语义回归用例。
- #185330 [[inductor] torch.index_select on uint16 input silently succeeds while eager/aot_eager raise NotImplementedError](https://github.com/pytorch/pytorch/issues/185330)  
  - 关注原因: eager/compiled 行为分叉且 compiled 静默成功，属于 API 契约偏差。  
  - 建议动作: 对齐 eager dtype legality check，并在 lowering 前统一抛错策略。
- #185074 [[RFC] torch.compile + CUDA graph capture: Inductor JIT has no capture-state awareness, causes CPU→GPU copy error on first call](https://github.com/pytorch/pytorch/issues/185074)  
  - 关注原因: 涉及 CUDA graphs/ROCm，且描述含“ROCm 下可能 silent wrong result”；已有 maintainer 接手。  
  - 建议动作: 跟进在 capture 中首次 compile 的显式报错方案，避免 silent fallback。
