# PyTorch Compiler Issue Digest - 2026-07-02

## 今日概览

- 共匹配 22 个 issue：15 个 open，7 个 closed。
- 今日主风险是 Inductor/Triton correctness：#188492 仍 open 且标记 high priority / silent correctness；#187935 已修复但暴露 signed-zero 测试缺口。
- 主要主题：torch.compile vs eager 语义不一致、Inductor/Triton codegen 回归、distributed/DTensor 编译缓存与 alias 问题、CI/test signal 噪声。
- 有 high-priority / silent-correctness 项：#188492 open；#187935 closed fixed；#188680 建议补强测试框架以捕获类似问题。

## 重点关注

1. #188492 [swin_base_patch4_window7_224 fails inductor accuracy (bf16 inference, H100) after Triton 3.8 pin](https://github.com/pytorch/pytorch/issues/188492)
   - 关注原因：H100 bf16 inference silent accuracy regression，且受 Triton 3.8 pin 影响，已有单变量 repro。
   - 建议动作：尽快决定 Triton 侧 Hopper mitigation、临时 pin/revert，或在 release gate 中阻断。

2. #188332 [Inductor: allgather fusion creates rank-specific cache that crashes when loaded by other ranks](https://github.com/pytorch/pytorch/issues/188332)
   - 关注原因：distributed warm FX graph cache 可能跨 rank 复用 rank/device-specific wrapper，导致运行时 crash。
   - 建议动作：确认 cache key 是否需要包含 rank/device/all-gather offset，补一个多 rank warm-cache 回归测试。

3. #184002 [[DTensor][Compile] Compile fails when DTensor function returns an aliased output](https://github.com/pytorch/pytorch/issues/184002)
   - 关注原因：DTensor + torch.compile + aliased output 触发 `as_strided not supported with DTensor`，影响 distributed compile。
   - 建议动作：在 AOTAutograd alias replay 或 DTensor 路径中明确支持/规避 aliased output。

4. #188358 [[Dynamo] Eager and torch.compile behavior mismatch in F.batch_norm with multidimensional bias](https://github.com/pytorch/pytorch/issues/188358)
   - 关注原因：eager 可运行但 `torch.compile(backend="aot_eager")` 抛错，属于语义一致性问题。
   - 建议动作：先确定 multidimensional bias 是否应被合法支持；随后统一 eager/compiled 行为并加测试。

5. #188680 [[test] OpInfo gap: allclose-based compile-vs-eager checks are blind to signed-zero and signed-infinity divergences](https://github.com/pytorch/pytorch/issues/188680)
   - 关注原因：解释了 #187935 这类 signed-zero silent correctness 为什么可能逃过现有 compile-vs-eager 测试。
   - 建议动作：维护者给出 actionable 范围，优先为 `signbit` / `isinf` / `isnan` 增加 opt-in parity 检查。
