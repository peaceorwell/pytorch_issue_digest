# PyTorch Compiler Issue Digest - 2026-07-01

## 今日概览

- 共匹配 17 个 issue：14 个 open，3 个 closed。
- 今日主要风险信号是 Inductor / torch.compile 的 silent correctness：CUDA special function、H100 bf16 Triton 3.8、subnormal sign behavior 都有明确 eager vs compiled 差异。
- 主题集中在 Inductor：accuracy regression、CI/compile-time timeout、GB200 reduction heuristic、attention layout fusion miss、CPU dynamic shape lowering crash。
- Dynamo 侧主要是 Pybind11 enum infinite recursion 和 CUDA EventVariable type metadata；其中 Pybind11 issue 已有人跟进。
- 高优先级或 silent-correctness 项明确存在：#188545、#188492、#188541；#188420 也报 output mismatch，但 maintainer 怀疑是 dropout seed，证据较弱。

## 重点关注

- [#188492 swin_base_patch4_window7_224 fails inductor accuracy (bf16 inference, H100) after Triton 3.8 pin bump](https://github.com/pytorch/pytorch/issues/188492) — 关注原因: high priority + silent correctness，控制变量显示 Triton 3.7.1 pass、3.8.0 fail。建议动作: 先缩小到具体 Triton kernel/IR，并决定是否需要临时回滚或屏蔽受影响配置。
- [#188541 [Inductor][CUDA] F.logsigmoid flushes negative float32 subnormal outputs to +0.0, changing sign-sensitive behavior](https://github.com/pytorch/pytorch/issues/188541) — 关注原因: silent correctness，signbit、zero check、copysign 都可观测改变。建议动作: 检查 CUDA lowering/fast-math/FTZ 路径，并补 subnormal edge-case 测试。
- [#188545 [PT2] Output mismatch between eager and torch.compile for torch.special.bessel_y0 with +inf input on CUDA](https://github.com/pytorch/pytorch/issues/188545) — 关注原因: high priority + silent correctness，+inf 输入从 NaN 变成 0。建议动作: 给 special/CUDA owner 复现，确认是否需要 Inductor guard、decomposition fix 或 Triton/libdevice 侧处理。
- [#188564 rocm-navi31 gfx1100 test (default) jobs time out after 270 min on inductor/test_torchinductor (red since 2026-05-20)](https://github.com/pytorch/pytorch/issues/188564) — 关注原因: ROCm gfx1100 CI 持续红约 6 周，`test_torchinductor` 超出 270 分钟预算。建议动作: 验证 #178945 的 ROCm Triton conv-bwd autotuning 影响，短期增加 shard 或限制 gfx1100 上相关 autotune。
- [#188514 [inductor][cpu] detectron2_maskrcnn_r_101_fpn & detectron2_maskrcnn_r_50_c4 fail accuracy in cpu_inductor_amp_freezing (regressed ~2026-06-11)](https://github.com/pytorch/pytorch/issues/188514) — 关注原因: CPU Inductor AMP freezing accuracy 持续失败，且有明确回归窗口。建议动作: 对 #186441 与 torchvision pin bump 做输出差异/bisect，确认是否重开或延续 #127073。
- [#188515 inductor-pallas TPU build broken: kineto installs ITraceActivity.h but not its new dependency TypedMetadata.h](https://github.com/pytorch/pytorch/issues/188515) — 关注原因: inductor-pallas TPU build every recent main red，属于 packaging/build break。建议动作: 推进 Kineto submodule bump #188550，并确认 `TypedMetadata.h` / `EnvMetadata.h` 安装列表完整。
