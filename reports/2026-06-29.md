# PyTorch Compiler Issue Digest - 2026-06-29

## 今日概览

- 今日匹配 5 个 Issue：open 4 个，closed 1 个。
- 主要风险信号是 Inductor 分布式 FX graph cache 可能复用 rank-specific 代码，导致多 GPU warm-cache 崩溃。
- 主题集中在 Inductor runtime crash、CUDA Graph capture、Dynamo 类型建模，以及 `torch.compile`/eager 行为不一致。
- 未看到 silent-correctness 证据；问题表现均为 crash、RuntimeError 或行为不一致。
- 高优先级关注项：#188332；#188355 也值得跟踪，因为已有 workaround 但涉及 CUDA graphs/max-autotune 路径。

## 重点关注

- [#188332 Inductor: allgather fusion creates rank-specific cache that crashes when loaded by other ranks](https://github.com/pytorch/pytorch/issues/188332)
  - 关注原因: 多 GPU distributed + shared FX graph cache 下，rank/device-specific generated wrapper 可能被其他 rank 复用，影响 Inductor cache 正确性与稳定性。
  - 建议动作: 复现两次 warm-cache 流程，确认 cache key 是否缺少 rank/device/all-gather packing offset，并补 distributed cache regression test。

- [#188355 [Inductor][CUDA Graphs] max-autotune attempts to capture torch.linalg.eigh and crashes with cudaErrorStreamCaptureUnsupported](https://github.com/pytorch/pytorch/issues/188355)
  - 关注原因: `torch.compile(mode="max-autotune")` 在 CUDA Graph capture `torch.linalg.eigh` 时崩溃；`max-autotune-no-cudagraphs` 可绕过，说明问题聚焦在 CUDA graphs capture policy。
  - 建议动作: 确认 `_linalg_eigh` 是否应被标记为 CUDA Graph unsafe，并在 max-autotune 路径加入跳过/降级逻辑和 regression test。

### #188325 torch._dynamo: EventVariable.python_type() returns torch.Event instead of type(self.value)

- 链接: https://github.com/pytorch/pytorch/issues/188325
- 状态: closed; 更新时间: 2026-06-29T01:47:50Z; 关键词: dynamo
- 标签: module: cuda, module: dynamo, triaged
- 摘要: Dynamo 的 `EventVariable.python_type()` 疑似硬编码返回 `torch.Event`，导致后续 `SuperVariable` 的 MRO 查找失败。
- 领域: Dynamo
- 类型: bug
- 影响: medium，CUDA stream/event 变量建模错误会触发编译期异常，但 Issue 已关闭且无评论说明。
- 关键信号: 有最小 repro；报错为 `ValueError: tuple.index(x): x not in tuple`；body 提到 `StreamVariable` 可能同类问题。
- 建议跟进: 查明关闭原因，若已修复则补覆盖 `EventVariable`/`StreamVariable.python_type()` 的 regression test。

### #188227 [inductor] generated kernel calls `empty_strided_cpu` with a negative stride → `Expected result >= 0`

- 链接: https://github.com/pytorch/pytorch/issues/188227
- 状态: open; 更新时间: 2026-06-28T13:48:56Z; 关键词: inductor
- 标签: oncall: cpu inductor
- 摘要: Inductor CPU 路径生成 `empty_strided_cpu((0, 0), (-1, 0), ...)`，eager 可运行但 compiled path 崩溃。
- 领域: Inductor
- 类型: bug
- 影响: medium，compiled-only runtime crash，涉及 zero-size tensor 和 negative stride 处理。
- 关键信号: repro 使用 `float_power`、`empty_strided`、`gather`；评论中有人认领并提出在 `empty_strided` 校验或在 Inductor 避免生成 negative stride，但没有 maintainer 结论。
- 建议跟进: 明确 eager/Inductor 对 zero-size negative stride 的契约，优先在 Inductor 生成端避免非法 stride，并添加 CPU regression test。

### #188332 Inductor: allgather fusion creates rank-specific cache that crashes when loaded by other ranks

- 链接: https://github.com/pytorch/pytorch/issues/188332
- 状态: open; 更新时间: 2026-06-28T12:27:00Z; 关键词: inductor
- 标签: 无
- 摘要: bucketed all-gather lowering 生成 rank/device-specific wrapper，但 FX graph cache key 似乎跨 rank 共享，warm cache 复用后崩溃。
- 领域: Inductor, distributed
- 类型: bug
- 影响: high，分布式缓存复用错误可能影响多 rank 训练稳定性，且 repro 指向 cache correctness。
- 关键信号: 两次 `torchrun --nproc-per-node 2` 复现；错误包括 `CUDA driver error: invalid argument` 或 Triton pointer access error；评论也指出 FxGraphCache key 可能缺少 rank。
- 建议跟进: 检查 all-gather fusion wrapper 中 baked-in 的 device/stream/offset 信息，修正 cache key 或避免缓存 rank-specific artifact。

### #188358 [Dynamo] Eager and torch.compile behavior mismatch in F.batch_norm with multidimensional bias

- 链接: https://github.com/pytorch/pytorch/issues/188358
- 状态: open; 更新时间: 2026-06-28T09:43:35Z; 关键词: compile, dynamo
- 标签: 无
- 摘要: `F.batch_norm` 对 3D `bias` eager 可通过，但 `torch.compile(backend="aot_eager")` 报 RuntimeError。
- 领域: torch.compile
- 类型: bug
- 影响: medium，eager/compiled 行为不一致，可能暴露 meta/checking 或 decomposition contract 差异。
- 关键信号: repro 中 `bias_3d.numel() == C`；期望是 compiled 与 eager 一致，或 eager 明确拒绝；无评论，证据来自单个 repro。
- 建议跟进: 先确认 multidimensional bias 是否是合法 eager 行为，再让 compiled path 对齐或统一报错，并补 `F.batch_norm` shape regression test。

### #188355 [Inductor][CUDA Graphs] max-autotune attempts to capture torch.linalg.eigh and crashes with cudaErrorStreamCaptureUnsupported

- 链接: https://github.com/pytorch/pytorch/issues/188355
- 状态: open; 更新时间: 2026-06-28T07:41:16Z; 关键词: inductor
- 标签: triage review, has workaround, module: linear algebra, module: cuda graphs, module: inductor
- 摘要: `torch.compile(mode="max-autotune")` 捕获包含 `torch.linalg.eigh` 的 CUDA Graph 时第二次迭代崩溃。
- 领域: Inductor
- 类型: bug
- 影响: medium，影响 max-autotune + CUDA graphs，但 body 显示 `max-autotune-no-cudagraphs` 可绕过。
- 关键信号: 环境为 `torch: 2.14.0.dev20260624+cu130`、CUDA 13.0；错误为 `cudaErrorStreamCaptureUnsupported` 和 capture invalidated；eager 与 no-cudagraphs 模式通过。
- 建议跟进: 将 `torch.linalg.eigh`/`aten._linalg_eigh` 纳入 CUDA Graph capture 兼容性判断，必要时自动禁用该 partition 的 cudagraph capture。
