# PyTorch Compiler Issue Digest - 2026-07-03

## 今日概览

- 共匹配 10 个 issue：8 个 open，2 个 closed。
- 今日主要风险信号是数值正确性回归：XPU TF32 silent correctness、Triton 3.8 相关 compile + float8 / A100 accuracy 异常。
- 主题集中在 Inductor：Triton pin、TMA、ROCm/HF benchmark、CUDA float32 GELU test disable。
- Dynamo 侧有两个 backend breakage：TVM 依赖 upstream API 移除，`ts`/`aot_ts` 被 LazyGraphModule 影响。
- 存在 high-priority / silent-correctness 项：#187947；另有多个 CI red 或 accuracy divergence 需要优先分流。

## 重点关注

- [#187947 Inductor mm template uses CUDA TF32 flag on XPU, diverging from eager](https://github.com/pytorch/pytorch/issues/187947)
  - 关注原因: 标记为 high priority 和 `module: correctness (silent)`，compiled XPU matmul 与 eager 使用不同 TF32 flag。
  - 建议动作: 按设备选择 TF32 flag，XPU 路径改用 `torch.backends.mkldnn.allow_tf32` / `allowTF32OneDNN()` 并补回归测试。

- [#188841 triton 3.8 pin update regressing compile + float8 training numerics](https://github.com/pytorch/pytorch/issues/188841)
  - 关注原因: Triton 3.8 pin 后 compile + float8 training numerics 回归，已有 standalone repro，回退 Triton pin 可缓解。
  - 建议动作: 先 bisect Triton 3.7 -> 3.8，聚焦评论里提到的 `grad_weight = x.t() @ grad_output` GEMM 形状。

- [#188835 DistillGPT2 fails accuracy on A100 in inductor smoke test](https://github.com/pytorch/pytorch/issues/188835)
  - 关注原因: A100/sm80 上 compiled-vs-eager RMSE 明显偏离，当前只是从 smoke check 中排除。
  - 建议动作: 从 DistillGPT2 缩小到具体 op / graph segment，并与 Triton 3.8 变更关联验证。

- [#188872 [dynamo] ts and aot_ts backends broken by LazyGraphModule](https://github.com/pytorch/pytorch/issues/188872)
  - 关注原因: 报告称 `ts` 和 `aot_ts` backend 对任意函数失败，CI 因测试 skip 可能未覆盖真实用户路径。
  - 建议动作: 在 scripting 前重建普通 `GraphModule`，同时加不依赖 `_force_skip_lazy_graph_module()` 的 backend 测试。

- [#188851 [CI][ROCm] DebertaV2ForMaskedLM fails to import from transformers on gfx950 (dynamic_inductor_huggingface eager_fail_to_run)](https://github.com/pytorch/pytorch/issues/188851)
  - 关注原因: ROCm periodic benchmark red，但证据指向 `transformers` import failure，不是 Inductor 编译回归。
  - 建议动作: 短期合入 ROCm expected CSV re-baseline，长期检查 ROCm image 的 transformers 依赖缺口。

## Issue 分析

### #188866 [dynamo] TVM backend fails to import with all pip-installable TVM versions (relay removed in TVM 0.20)

- 链接: https://github.com/pytorch/pytorch/issues/188866
- 状态: open; 更新时间: 2026-07-03T03:44:18Z; 关键词: dynamo
- 标签: `module: dependency bug`, `module: third_party`, `module: backend`, `module: dynamo`
- 摘要: PyTorch 内置 TVM Dynamo backend 依赖已被 TVM 0.20+ 移除的 `tvm.relay`，当前 PyPI TVM 版本无法正常 import。
- 领域: Dynamo
- 类型: bug
- 影响: medium，第三方 backend 全量不可用但影响面相对窄。
- 关键信号: `BackendCompilerFailed` 包含 `ImportError: cannot import name 'relay' from 'tvm'`；`apache-tvm==0.25.0.post1`；TVM 自带 `relax_dynamo` backend 被报告可用。
- 建议跟进: 决定 deprecated 还是 delegate 到 TVM 自带 backend，并修正误导性的安装提示。

### #188872 [dynamo] ts and aot_ts backends broken by LazyGraphModule

- 链接: https://github.com/pytorch/pytorch/issues/188872
- 状态: open; 更新时间: 2026-07-03T02:38:54Z; 关键词: dynamo
- 标签: 无
- 摘要: `use_lazy_graph_module` 默认开启后，`ts` 和 `aot_ts` backend 传入 `_LazyGraphModule` 导致 `torch.jit.script` 失败。
- 领域: Dynamo
- 类型: regression
- 影响: medium，backend 据称对任意函数失败，但属于较专门路径。
- 关键信号: repro 使用 `torch.compile(..., backend="ts")`；错误为 `_lazy_graph_module.py` 中 `method cannot be used as a value`；报告称重建普通 `GraphModule` 可修复。
- 建议跟进: 在 TS backend scripting 前 materialize `GraphModule`，并添加覆盖 LazyGraphModule 默认路径的测试。

- 建议跟进: 确认 closed 对应修复已覆盖 XPU device branch，并保留 `test_max_autotune` 或等价回归测试。
