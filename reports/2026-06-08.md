# PyTorch Compiler Issue Digest - 2026-06-08

## 今日概览

- 今日匹配到 18 个 issue：4 个 open，14 个 closed。
- 主要风险信号是 Inductor 相关 silent correctness：`layer_norm` fusion 产生错误结果，以及 activation checkpoint recompute 选择不同 reduction config。
- 主题集中在 `torch.compile` 正确性/崩溃、Inductor dynamic shapes 与 Triton/device-side assert、Dynamo 配置线程隔离、以及若干 closed issue 的复现状态不一致。
- 高优先级或 silent-correctness 项存在：#186577、#186572、#147108；#175058 是 high priority 但评论称已在 2.12 修复。

## 重点关注

- #186577 [`torch.compile` produces wrong results when `F.layer_norm` is fused with `reciprocal`/`rsqrt` epilogue](https://github.com/pytorch/pytorch/issues/186577)：关注原因: open silent correctness，Inductor fusion 后与 eager/`aot_eager` 差异明显；建议动作: 优先复现并 bisect fusion/codegen 路径，补充 reduction/norm epilogue 正确性测试。
- #186572 [[Inductor] Checkpointed reductions can choose different configs between forward and recompute](https://github.com/pytorch/pytorch/issues/186572)：关注原因: open silent correctness/determinism，activation checkpoint recompute 与 forward 可能低位漂移并影响离散路由；建议动作: 检查 AC recompute 编译缓存/autotune config 复用策略。
- #186536 [[inductor] Dynamic-shape `searchsorted`-derived index trips a device-side bounds assert on in-bounds CUDA inputs](https://github.com/pytorch/pytorch/issues/186536)：关注原因: open CUDA dynamic-shape valid input 触发 device-side assert；建议动作: 复现后看 Inductor range analysis 是否能关联 `values.size(0) == offsets[-1]`，或避免生成会误触发的 assert。
- #186537 [torch 2.12 regression: torch.compile thread-local config - even backward thread has separate config](https://github.com/pytorch/pytorch/issues/186537)：关注原因: open regression/BC-breaking，autograd worker thread 可能拿不到调用线程 Dynamo config；建议动作: 验证 repro，决定 backward thread 是否应继承 launching thread 的 config。
- #185405 [[Inductor] AssertionError: len(index) == len(stride) in ir.py when using torch.compile(mode="max-autotune") on CPU BMM/GEMM](https://github.com/pytorch/pytorch/issues/185405)：关注原因: issue 已 closed，但最新评论称 2.13 nightly 仍可复现；建议动作: 用评论里的 git version 重新跑 CPU `max-autotune` repro，若确认则 reopen。
