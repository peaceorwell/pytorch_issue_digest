# PyTorch Compiler Issue Digest - 2026-06-08

## 今日概览

- 今日标题匹配 `compile` / `inductor` / `dynamo` 的 Issue 共 17 个：open 3 个，closed 14 个。
- 主要风险信号是 open 的 Inductor silent correctness / determinism 问题：activation checkpointing recompute 可能选择不同 reduction config。
- 重点主题包括：dynamic shapes 下的 CUDA / Triton 断言、Dynamo 线程本地配置回归、torch.compile 与 eager 的 dtype / metadata 语义不一致。
- 有高优先级或 silent-correctness 信号：#186572 明确标记 `module: correctness (silent)`；#147108 虽为 closed，但 recent comment 显示 nightly 上仍可复现 dtype divergence。

## 重点关注

- [#186572 [Inductor] Checkpointed reductions can choose different configs between forward and recompute](https://github.com/pytorch/pytorch/issues/186572)
  - 关注原因: open，带 `module: correctness (silent)` / `module: determinism`，activation checkpointing forward 与 recompute 独立编译后可能产生低位差异并影响离散决策。
  - 建议动作: 先在 nightly 上确认 repro，再检查 checkpoint recompute 是否应复用或锁定 reduction/autotuning config。

- [#186536 [inductor] Dynamic-shape `searchsorted`-derived index trips a device-side bounds assert on in-bounds CUDA inputs](https://github.com/pytorch/pytorch/issues/186536)
  - 关注原因: open，valid CUDA input 在 `torch.compile(dynamic=True)` 下触发 device-side assert，eager 和 CPU compile 均正确。
  - 建议动作: 生成 minifier，聚焦 `searchsorted` range analysis 与 `values.size(0) == offsets[-1]` 这类符号关系。

- [#186537 torch 2.12 regression: torch.compile thread-local config - even backward thread has separate config](https://github.com/pytorch/pytorch/issues/186537)
  - 关注原因: open，标记 regression / bc-breaking / multithreading；Dynamo config thread-local 后 autograd backward thread 不继承调用线程配置，可能 hard fail 或 fallback eager。
  - 建议动作: 用非 AI-generated 最小 repro 复核，并决定 backward worker 是否复制 Dynamo config context。

- [#147108 Inconsistent data type casting decision when using `torch.addmv` under torch.compile and eager](https://github.com/pytorch/pytorch/issues/147108)
  - 关注原因: closed 但 recent comment 表示 PyTorch nightly `2.13.0.dev20260516+cu132` on H100 仍能复现 eager int32 vs torch.compile float32 的 silent semantic divergence。
  - 建议动作: 若当前 nightly 仍复现，应重新打开或补充 closure reason，并明确 eager vs compile 的目标 dtype 语义。
