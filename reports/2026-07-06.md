# PyTorch Compiler Issue Digest - 2026-07-06

## 今日概览

- 今日匹配 issue 11 个：open 3 个，closed 8 个。
- 主要风险信号：open 项里有 `torch.compile` 触发 segfault、Windows nightly 编译回归，以及 Inductor OpInfo 非 CUDA 覆盖缺口。
- 主题集中在 Inductor 测试覆盖/缓存进程池、MKLDNN `to_dense()` layout/storage 转换、Windows `compiled_autograd.h` 编译错误、动态 shape/`eager_then_compile`。
- 有高优先级 crash/CI 覆盖项；未看到明确 silent-correctness 证据，主要是 crash、compile error、warning、性能或测试覆盖问题。

## 重点关注

- [#160399 `torch.compile` causes segmentation fault with simple `ModuleList` model after multiple compile calls](https://github.com/pytorch/pytorch/issues/160399)
  - 关注原因: 最小复现显示进程级 segfault；评论指出 CPU compiled version 被复用到 CUDA weights，至少需要更好的错误边界。
  - 建议动作: 在当前 nightly 复现，评估给 Inductor C++ generated code 加 device check 或在 `model.to()` 后失效相关 compiled state。

- [#148317 compile SageAttention faing error C2872: “std” for latest torch nightly](https://github.com/pytorch/pytorch/issues/148317)
  - 关注原因: open regression；证据显示 MSVC 14.42 到 14.50 都触发 `compiled_autograd.h` 的 `std` ambiguous symbol，影响 Windows extension/用户编译路径。
  - 建议动作: 用 Windows CI 或一行 C++ extension repro 固化问题，检查 `torch/csrc/dynamo/compiled_autograd.h` 命名空间/限定名修复。

- [#161132 The Inductor test suite test_torchinductor_opinfo was incorrectly disabled on all devices except CUDA.](https://github.com/pytorch/pytorch/issues/161132)
  - 关注原因: Inductor OpInfo 在非 CUDA 设备上的大测试套件覆盖被跳过；最新评论称修复 PR 自动关闭后又被 auto-revert。
  - 建议动作: 重新拆分或调整 CPU Inductor OpInfo CI timing 后重落覆盖修复，避免单纯 revert 导致 timeout。

- [#183773 torch.compile raises RuntimeError on MKLDNN tensor to_dense followed by arithmetic](https://github.com/pytorch/pytorch/issues/183773)（关联 #182402/#160873）
  - 关注原因: 多个 closed issue 指向同一类 MKLDNN `to_dense()` + arithmetic 编译失败；repro agent 曾 3/3 复现。
  - 建议动作: 确认关闭对应的修复已带回归测试，覆盖 MKLDNN input、`to_dense()`、dynamic/fullgraph、AOT/Inductor 路径。

### #160399 `torch.compile` causes segmentation fault with simple `ModuleList` model after multiple compile calls

- 链接: https://github.com/pytorch/pytorch/issues/160399
- 状态: open; 更新时间: 2026-07-05T20:06:55Z; 关键词: compile
- 标签: oncall: pt2, oncall: cpu inductor
- 摘要: 同一模型多次 `torch.compile` 后再原地 `model.to('cuda')`，运行已编译路径触发 segfault。
- 领域: torch.compile
- 类型: bug
- 影响: high，segfault 是进程级崩溃，即使根因可能是跨 device 使用 compiled state。
- 关键信号: 最小 `ModuleList`/Conv2d repro；PyTorch 2.7/2.8 nightly；评论给出根因是 CPU compiled code 持有后 weights 被移到 CUDA。
- 建议跟进: 当前 nightly 复现后加 device mismatch guard 或 compiled cache invalidation，并返回结构化错误。
