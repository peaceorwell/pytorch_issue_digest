# PyTorch Compiler Issue Digest - 2026-05-22

## 今日概览

- 今日命中标题关键词（compile/inductor/dynamo）的 issue 共 52 条，其中 open 16 条、closed 36 条。
- 当日主要风险信号是“数值正确性与语义一致性”：`torch.compile` 与 eager 在误差、异常类型、越界检查上的一致性仍有新增 open 反馈。
- 主要主题集中在：Inductor 动态形状/符号绑定、CUDA/CPU 数值偏差、CI disabled/flaky 与性能不稳定、以及 distributed + Dynamo 的编译能力补齐。
- 高优先级条目仍存在（含 `high priority`/`module: crash`/`module: regression`）；显式 `module: correctness (silent)` 的条目今天多为已关闭，但需持续防回归。
- 证据强度不均：部分数值偏差问题有复现代理确认，部分仅报告相对误差且容差/期望尚在讨论，需保守判断。

## 重点关注

- [#184408](https://github.com/pytorch/pytorch/issues/184408) `torch.div(rounding_mode='trunc')` produces off-by-one results under `torch.compile` on CUDA  
  关注原因: 明确“off-by-one”正确性偏差，且为 open。  
  建议动作: 先补最小回归测试（含 near-integer 与 exact-integer 样例），再定位 lowering/rounding 路径差异。

- [#181115](https://github.com/pytorch/pytorch/issues/181115) [inductor] torch.compile(dynamic=True) crashes in TorchInductor CPU codegen with AttributeError: 'StrictLessThan' object has no attribute 'diff'  
  关注原因: `module: crash` + dynamic shapes + CPU codegen 崩溃，且复现代理已确认。  
  建议动作: 以报错栈为入口锁定 symbolic_shapes/vectorization 交界逻辑，先做防御性修复避免 hard crash。

- [#168126](https://github.com/pytorch/pytorch/issues/168126) Large numeric divergence for torch compile vs eager in bf16  
  关注原因: `high priority` 且 nightly/H100 复现成功，影响 bf16 数值可信度。  
  建议动作: 固化最小 repro 到 accuracy 套件，分解定位到 decomposition/AOT dispatch 具体变换点。

- [#183401](https://github.com/pytorch/pytorch/issues/183401) [inductor][cpu] resnet50_quantized_qat CPP wrapper torch._inductor.exc.InductorError: CppCompileError: C++ compile error in 2026-05-11 nightly release  
  关注原因: `module: regression`，影响量化模型 CPU 编译可用性。  
  建议动作: 对比 2026-05-11 前后 nightly 变更做二分，优先加 CI 覆盖 quantized_qat CPP wrapper。

- [#182084](https://github.com/pytorch/pytorch/issues/182084) Torch.compile crashes with multi-stream and triton kernels  
  关注原因: multi-GPU + compiled streams 崩溃，涉及 Triton 代码生成命名/流切换路径。  
  建议动作: 先合入最小防冲突修复（stream id/object 命名隔离），并补 `cuda:1+` 多流回归测试。

- [#183833](https://github.com/pytorch/pytorch/issues/183833) [Inductor][HOP] FlexAttention should bind derived unbacked tensor input extents from runtime metadata

  建议动作: 在 regional Inductor/codegen 路径优先绑定输入元数据表达式而非父符号，补 FlexAttention 分块场景测试。

- [#161295](https://github.com/pytorch/pytorch/issues/161295) UNSTABLE inductor-periodic / cuda12.8-py3.10-gcc9-sm80 / test (inductor_torchbench_smoketest_perf)

  建议动作: 临时固定稳定基准/阈值并记录硬件条件，随后拆分“性能退化”与“噪声抖动”两类根因。
