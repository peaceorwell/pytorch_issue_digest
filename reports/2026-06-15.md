# PyTorch Compiler Issue Digest - 2026-06-15

## 今日概览

- 共 21 个匹配 issue（open 7 / closed 14），均按标题 case-insensitive 命中 compile、inductor 或 dynamo。
- 今日最强风险信号是 open 的 silent correctness：#187284 中 `torch.compile` + `inductor` 会丢失 forward-mode AD tangent。
- 主要主题：silent correctness / error-checking divergence、Windows / MKLDNN / XPU 平台边界、dynamic shapes + FlexAttention / combo kernels、Dynamo 配置与 UX。
- 有高优先级或 silent-correctness 项：open 的 #187284；closed 的 #184893、#177839、#182965，以及 #121135 的错误检查绕过，建议确认回归测试覆盖。

## 重点关注

- [#187284 `torch.compile` with `inductor` backend silently drops forward-mode AD tangents (returns `None`)](https://github.com/pytorch/pytorch/issues/187284)
  - 关注原因: open 且标记 `module: correctness (silent)`；eager / `cudagraphs` 有 tangent，Inductor 返回 `None`，评论还提到 Hessian 变 0。
  - 建议动作: 在 latest main 复现，明确 Inductor 是否支持 forward-mode AD；若不支持应显式报错，若支持需加 JVP / Hessian 回归测试。

- [#186537 torch 2.12 regression: torch.compile thread-local config - even backward thread has separate config](https://github.com/pytorch/pytorch/issues/186537)
  - 关注原因: open regression / bc-breaking；Dynamo config thread-local 后，torch 管理的 backward / checkpoint 线程可能看不到调用线程配置。
  - 建议动作: 确认 autograd-managed threads 复制 context/config 的修复范围，并补 release note 或迁移说明。

- [#187283 torch.compile fails on Windows with `FileNotFoundError` (`.ttir`) when Inductor's descriptive Triton kernel name pushes the cache path past MAX_PATH (260)](https://github.com/pytorch/pytorch/issues/187283)
  - 关注原因: open Windows regression；默认 long paths disabled 时，长 Triton kernel 文件名导致 `.ttir` cache path 超过 260。
  - 建议动作: 选择 Windows 文件名 hash/truncate 或 extended path 策略，同时保留 metadata 中的 descriptive name，并加 path-length 测试。

- [#187272 Dynamo graph-breaks on raw unbacked SymInt inputs during non-strict FlexAttention tracing](https://github.com/pytorch/pytorch/issues/187272)
  - 关注原因: open；阻塞 FlexAttention 在 non-strict tracing / unbacked symbolic sequence length 场景下继续 trace。
  - 建议动作: 评估 `VariableBuilder` 对 raw unbacked `SymInt` 的 symbolic-only 支持，并加 FakeTensor / BlockMask repro 测试。

- [#187269 torch._inductor.config.combo_kernels = True` crashes inductor codegen with "Dynamic shape on reduction dimension is not supported"](https://github.com/pytorch/pytorch/issues/187269)
  - 关注原因: open codegen crash；虽然 `combo_kernels=False` 是 workaround/default，但暴露 dynamic reduction + persistent reduction 分支缺口。
  - 建议动作: 在 combo grouping 阶段跳过 dynamic persistent reductions，或降级为 non-persistent 路径；跟进作者承诺的 PR。
