# PyTorch Compiler Issue Digest - 2026-05-15

## 今日概览

- 今日标题命中 `compile/inductor/dynamo` 的 issue 共 **65** 条；其中 **open 49**、**closed 16**。  
- 主要风险信号是 **silent correctness 聚集**：多条 open issue 指向 `torch.compile` 与 eager 在数值/校验行为上的不一致。  
- 主要主题集中在：`Inductor` 正确性与边界行为、`dynamic shapes`/unbacked SymInt、编译期性能与 functionalization 设计、`Dynamo` 回归测试与导出报错。  
- 存在高优先级条目（`high priority` + 可复现 correctness 问题），也有文档/问答型低风险条目。  
- 证据强度不均：部分新 issue 仅有初始描述或 bot 分类，结论仍需维护者复现确认。  

## 重点关注

- [#181696 Eval-mode `BatchNorm`/`GroupNorm` produces wrong output under `torch.compile(backend='inductor')`](https://github.com/pytorch/pytorch/issues/181696)  
  - 关注原因: `high priority` + `correctness (silent)` + `repro_success`，直接影响推理正确性。  
  - 建议动作: 先补 eager 对照回归测试并确认受影响版本区间，必要时准备 backport。  

- [#181694 `torch.addcdiv` produces wrong output under `torch.compile(backend='inductor')`](https://github.com/pytorch/pytorch/issues/181694)  
  - 关注原因: 高优先级且复现成功，属于确定性错误输出风险。  
  - 建议动作: 以最小 repro 驱动修复 decomposition/lowering，并补 dtype/shape 覆盖测试。  

- [#178880 `torch.compile` produces different classification output for model using E8M0 bit-manipulation quantization (`view(int32) → bitshift → clamp → uint8`)](https://github.com/pytorch/pytorch/issues/178880)  
  - 关注原因: 分类结果偏差，且已标注 `high priority`。  
  - 建议动作: 先给出临时规避（禁用特定 fusion/decomposition），再推进根因修复。  

- [#183769 torch.compile skips out-of-range check for torch.select and returns invalid values](https://github.com/pytorch/pytorch/issues/183769)  
  - 关注原因: 跳过错误检查并返回无效值，属于行为一致性与 silent 风险叠加。  
  - 建议动作: 对齐 eager 的 error checking 语义，并补负例测试。  

- [#183372 torch.compile Inductor crashes on conv2d with bool-cast input and flattened bias](https://github.com/pytorch/pytorch/issues/183372)  
  - 关注原因: open crash，可能阻断用户落地。  
  - 建议动作: 固定 crash 栈与触发条件，先提供短期规避路径。  

- [#175966 Silently incorrect results for torch.arange + Inductor](https://github.com/pytorch/pytorch/issues/175966)  
  - 关注原因: 基础算子 silent incorrect，潜在影响面较大。  
  - 建议动作: 按 dtype/device/step 做系统化回归覆盖，并核查历史版本影响。
