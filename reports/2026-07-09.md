# PyTorch Compiler Issue Digest - 2026-07-09

## 今日概览

- 今日匹配 `compile` / `inductor` / `dynamo` 标题的 Issue 共 21 个：open 9 个，closed 12 个。
- 主要风险信号是 open 的 release/package regression：ROCm 2.13/2.14 nightly wheel 在非 ROCm 镜像中跑 CPU `torch.compile` smoke test 失败，且已有 revert 验证。
- 主题集中在 Inductor 回归/崩溃、Dynamo/ONNX export correctness 与清理、`torch.compile` 大规模 distributed cache/CPU device 行为。
- 有高优先级和 silent-correctness 信号：#189194 仍 open 且标记 high priority；#189225 是 ONNX GRU silent correctness，但已由 onnxscript 0.7.1 验证修复。
- 多个 closed 项目看起来是历史问题收口；open 项里 #189330、#189239、#185405、#168995 更值得 compiler maintainer 跟进。

## 关键主题

- **Inductor regression/crash**：layout optimization 对 backward-only conv graph 失效、CPU `max-autotune` BMM/GEMM crash、MXFP8 `DtypeView` reindexer NYI、scheduler self-edge KeyError。
- **Dynamo / ONNX export correctness**：PixelUnshuffle ordering、GRU `linear_before_reset`、nested repeated subgraph constants 等多项已关闭，但需要确认依赖版本和回归测试覆盖。
- **`torch.compile` scale/packaging UX**：ROCm wheel CPU smoke regression、MoE `ProcessGroup` specialization 导致 cache miss、CPU-only compile 初始化 CUDA context。
