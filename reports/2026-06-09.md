# PyTorch Compiler Issue Digest - 2026-06-09

## 今日概览

- 匹配标题关键词的 Issue 共 32 个：open 24 个，closed 8 个。
- 今日主风险信号是 Inductor silent correctness / numerics 集中出现，尤其是 dynamic shapes、bf16/type promotion、AOTI 动态维度恢复和 fused normalization。
- 主要主题包括：Inductor 数值正确性、Dynamo guard/cache 性能回退、2.12/vLLM 回归验证、CUDA/Triton compile worker 兼容性、compiled autograd / dynamic shapes 崩溃。
- 有 4 个 `high priority` Issue，12 个带 `module: correctness (silent)`；需要优先区分真实 compiler bug、已关闭/不可复现项和第三方 fake kernel 问题。

## 关键主题

- Inductor correctness 是最大簇：AOTI dynamic batch corruption、CPU/bf16 gradient mismatch、layer_norm epilogue fusion、checkpointed reductions、特殊函数和训练梯度错误。
- Dynamo 侧风险集中在 guard eval 性能回归、thread-local config 行为变化，以及 Python container 语义捕获错误。
- vLLM/2.12 相关 Issue 仍有一个 open：`assert_size_stride (8192 vs 512)` 仍在 RC validation 复现，但证据倾向 vLLM fake/meta kernel。
- 多个 closed Issue 的结论是“已修复 / 最新 nightly 不复现 / 非 Dynamo-Inductor 根因”，维护重点应放在仍 open 且 silent/high-priority 的项。
