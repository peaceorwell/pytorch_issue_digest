## Overview

- 26 issues matched by title keyword (`compile`/`inductor`/`dynamo`) in this snapshot; 21 open and 5 closed.
- Main themes:

- High-priority signal is present: at least two open issues are explicitly labeled `high priority` and involve correctness/crash risk.

## Priority Watchlist

- #181692: [`nn.RReLU().eval()` produces wrong output under `torch.compile(backend='inductor')`](https://github.com/pytorch/pytorch/issues/181692)

  Recommended next action: land/verify fix path with deterministic parity tests on eager vs compile for eval-mode RReLU.

- #183249: [`torch.compile` produces wrong results for `fractional_max_pool2d` when `_random_samples` is not provided](https://github.com/pytorch/pytorch/issues/183249)  
  Why it matters: silent correctness mismatch with explicit repro and nontrivial output/index divergence.  
  Recommended next action: prioritize RNG-state semantics parity test coverage for pooling path; decide short-term mitigation beyond manual `_random_samples`.

- #183325: [torch.compile + TMA path : Illegal Memory Access](https://github.com/pytorch/pytorch/issues/183325)  
  Why it matters: runtime illegal memory access on large tensors (GB200 context) can be production-blocking.  
  Recommended next action: reproduce with provided size/config boundary; bisect TMA offset/indexing path and add stress test around threshold.

- #181621: [torch.compile (Inductor) generates invalid C++ kernel: tmp8 used outside its declared scope when torch.gather index is a self-referential expression](https://github.com/pytorch/pytorch/issues/181621)  
  Why it matters: compile-time C++ codegen failure in core gather pattern; recently updated and still open.  
  Recommended next action: confirm on latest nightly (requested in-thread) and capture minimal generated C++ diff to isolate scoping bug.

- #181735: [[vLLM][inductor][triton] decompose_triton_kernel_wrapper_functional AssertionError under dynamic shapes](https://github.com/pytorch/pytorch/issues/181735)  
  Why it matters: labeled `high priority`; affects dynamic-shape + Triton integration in an ecosystem-critical workload (vLLM).  
  Recommended next action: coordinate owner already taking over; gate with targeted dynamic-shape regression test once fixed.
