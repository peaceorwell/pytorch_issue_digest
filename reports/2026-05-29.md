## 今日概览

- 今日匹配到 38 条 issue（标题包含 compile/inductor/dynamo），其中 open 31 条、closed 7 条。
- 主要风险信号是 Inductor 侧 silent correctness 集中出现：至少 11 条带 `module: correctness (silent)`，且多条涉及训练梯度错误或错误检查缺失。
- 主题集中在：dynamic shapes 符号比较/分支崩溃、bf16 类型提升与边界值行为偏差、custom op/FakeTensor 兼容性、max-autotune/Triton 路径稳定性。
- 存在高优先级与 silent-correctness 项（尤其 #185589、#182965、#185509、#185464、#185449）。

## 重点关注

1. [#185589 [inductor] Severe numerical inconsistency: diag_embed + erf + normalize(p=-1) under torch.compile(dynamic=True) — max diff up to 565,248](https://github.com/pytorch/pytorch/issues/185589)  
关注原因：静默数值错误且偏差极大（max diff 565,248），动态形状路径。  
建议动作：优先分派 Inductor correctness owner，先做最小化 repro + 定位 `diag_embed/normalize(p=-1)` lowering 链路。

2. [#182965 `torch.compile` silently returns a result for `torch.linalg.cholesky` on non-positive-definite input](https://github.com/pytorch/pytorch/issues/182965)  
关注原因：错误检查语义破坏（eager 抛错，compiled 静默返回），且已被 PT2 Repro Agent 在 nightly H100 复现。  
建议动作：按 correctness blocker 处理，补 eager/compile 抛错一致性测试（含 fullgraph）。

3. [#185509 [inductor] Silent incorrect gradients with interpolate, conv2d, max_pool2d and torch.where](https://github.com/pytorch/pytorch/issues/185509)  
关注原因：训练反向梯度静默错误，前向看似正常，风险高。  
建议动作：优先做 A/B bisect（decomposition/fusion/kernel）并加 grad parity regression。

4. [#185464 torch.compile produces wrong results for F.multilabel_margin_loss when target contains -1](https://github.com/pytorch/pytorch/issues/185464)  
关注原因：同时影响前向 loss 和反向 gradient，且在 Inductor 与 AOT eager 都出现。  
建议动作：先定位 decomposition 语义处理 `-1` sentinel 的分支，再补双后端一致性测试。

5. [#185449 Flash attention backend type not stored in inductor cache, causes silent usage of wrong backend](https://github.com/pytorch/pytorch/issues/185449)  
关注原因：缓存键遗漏 SDPA backend 选择，可能静默复用错误 backend。  
建议动作：将 backend type 纳入 cache key，并加跨 backend 切换回归测试。

6. [#182006 [vllm] vllm::sparse_attn_indexer custom op output aliases input — now hard-errors with new torch.compile aliasing check (DeepSeek-V3.2)](https://github.com/pytorch/pytorch/issues/182006)  
关注原因：生态兼容与 BC 风险（vLLM/DeepSeek），CI 与本地行为不一致（hard error vs warning）。  
建议动作：明确 CI 策略与豁免范围，推进已有 PR 路径并给下游迁移指引。

7. [#185472 [Inductor] `F.hardtanh` compiled backward silently drops gradient at bf16 boundary values](https://github.com/pytorch/pytorch/issues/185472)  
关注原因：bf16 边界值梯度静默丢失，且同类问题在 #185470/#185480/#185484/#185517 成簇出现。  
建议动作：统一审计 bf16 标量 cast/比较与 subnormal 处理，批量补 activation/loss 边界用例。
