# PyTorch Compiler Issue Digest - 2026-07-08

## 今日概览

- 共匹配 18 个标题含 `compile` / `inductor` / `dynamo` 的 issue：16 个 open，2 个 closed。
- 今日主风险集中在 release/packaging 与缓存特化：ROCm wheel 的 `torch.compile` smoke regression，以及 Inductor allgather warm-cache rank collision。
- 主题明显分为四类：silent correctness / runtime failure、distributed compile cache/guard、Inductor autotune 与性能、PrivateUse1 backend RFC。
- 有 high-priority 项：#189194、#188332；有 silent-correctness 或潜在 silent failure 信号：#189225、#189189。
- 多个性能项已有 draft PR 或可复现实验，但 RFC 类 issue 主要是设计讨论，证据不应按 bug 处理。

## 重点关注

1. [#189225 torch.onnx.export(dynamo=True) exports nn.GRU with wrong linear_before_reset=0](https://github.com/pytorch/pytorch/issues/189225)
   - 关注原因: ONNX Dynamo exporter 可能导出错误 GRU 语义，标签含 `module: correctness (silent)`，报告称 ONNXRuntime 数值误差最高 14%。
   - 建议动作: 复现 `onnxscript==0.6.2` 环境，修正 GRU lowering 的 `linear_before_reset`，补 ONNXRuntime 对比回归测试。

2. [#189194 [ROCm] torch 2.13 wheel: "Can't detect vectorized ISA for CPU" in torch.compile smoke test on non-ROCm image (regression vs 2.12.1)](https://github.com/pytorch/pytorch/issues/189194)
   - 关注原因: high priority release regression；`2.13.0+rocm7.2` 与 nightly 在 non-ROCm image 的 CPU/Inductor smoke test 失败。
   - 建议动作: 验证评论中指向的 #183515 VecISA dlopen 变更，补 non-ROCm image 的 ROCm wheel smoke 覆盖。

3. [#188332 Inductor: allgather fusion creates rank-specific cache that crashes when loaded by other ranks](https://github.com/pytorch/pytorch/issues/188332)
   - 关注原因: high priority；warm FX graph cache 可让 rank 1 载入 rank 0 的 rank/device-specific code，导致 CUDA/Triton crash。
   - 建议动作: 对 bucketed all-gather cache key 加 rank/device/codegen 特化，或先禁用该路径缓存并加 2-GPU 回归测试。

4. [#189189 Subtraction between two `torch.complex64` tensors fails on modules compiled with `aoti_compile_and_package`](https://github.com/pytorch/pytorch/issues/189189)
   - 关注原因: AOTI complex fallback 运行时报 C++ proxy executor contract 错误；评论称 CPU 也复现，且 `compiled(a, b)` 可能返回 `None` 而不抛异常。
   - 建议动作: 修复 `aten::sub.Tensor` kwarg-only `alpha` 在 AOTI proxy executor 的参数契约，并确保运行时错误显式传播。

5. [#189121 [inductor] Single-config reductions extended by _dynamic_scale_rblock are permanently uncacheable — re-benchmark {R0_BLOCK, R0_BLOCK/2} every process; near-tied winners flip perf and numerics](https://github.com/pytorch/pytorch/issues/189121)
   - 关注原因: Inductor reduction autotune cache contract 有缺口，可能导致每进程重复 benchmark，并在 near-tie 时出现性能和数值差异。
   - 建议动作: Review draft PR #189124，确认 DSR-eligible single-config reduction 能创建并持久化 autotune cache。

### #189225 torch.onnx.export(dynamo=True) exports nn.GRU with wrong linear_before_reset=0

- 链接: https://github.com/pytorch/pytorch/issues/189225
- 状态: open; 更新时间: 2026-07-08T02:51:26Z; 关键词: dynamo
- 标签: `module: onnx`, `module: rnn`, `module: correctness (silent)`
- 摘要: Dynamo ONNX exporter 对 `nn.GRU` 可能写出错误 `linear_before_reset=0`，导致 ONNX consumer 数值错误。
- 领域: export
- 类型: bug
- 影响: high，涉及 silent correctness，且有最小 repro 和误差描述。
- 关键信号: legacy TorchScript exporter 正确；评论补充 `onnxscript` 版本为 0.6.2。
- 建议跟进: 复现并修正 GRU ONNX lowering，添加 PyTorch vs ONNXRuntime 数值回归测试。

### #187073 torch.compile recompiles when input alternates between AsyncCollectiveTensor and Tensor

- 链接: https://github.com/pytorch/pytorch/issues/187073
- 状态: open; 更新时间: 2026-07-07T22:55:54Z; 关键词: compile
- 标签: `module: performance`, `module: fsdp`, `module: dynamo`, `module: guards`, `has workaround`
- 摘要: Dynamo guard 在 ACT 与 resolved Tensor 交替输入时反复 recompile，影响 FSDP + TP 场景。
- 领域: Dynamo
- 类型: performance
- 影响: medium，会造成分布式训练 compile cache 压力，但报告认为只放宽 ACT->Tensor 方向较安全。
- 关键信号: repro 使用 `torch.compile(fullgraph=True)` 和 `all_gather_tensor`；评论称 @williamwen42 会看。
- 建议跟进: 在 guard 逻辑中验证并支持 ACT trace 后 resolved Tensor runtime 的安全放宽。

### #189189 Subtraction between two `torch.complex64` tensors fails on modules compiled with `aoti_compile_and_package`

- 链接: https://github.com/pytorch/pytorch/issues/189189
- 状态: open; 更新时间: 2026-07-07T22:04:29Z; 关键词: compile
- 标签: `module: complex`, `module: aotinductor`, `oncall: export`, `has workaround`
- 摘要: `torch.export` 后经 AOTI package 的 complex64 subtraction 编译成功但运行失败。
- 领域: Inductor
- 类型: bug
- 影响: high，评论称错误可能只在 C++ 侧记录且 Python 返回 `None`，有 silent failure 风险。
- 关键信号: 报错为 `Mismatch between ints consumed and num_ints`；real/imag 手写拆分可绕过；CPU/CUDA 都可能复现。
- 建议跟进: 修复 AOTI proxy executor 对 `aten::sub.Tensor` 的 `alpha` 参数处理，并加 complex fallback 回归测试。
