# PyTorch Compiler Issue Digest - 2026-05-13

## 今日概览

- 今日标题命中 `compile/inductor/dynamo` 的 issue 共 **33** 条，其中 **open 28**、**closed 5**。
- 主要风险信号：`torch.compile` + Inductor 出现多起 **crash 与 silent correctness**（错误结果但不报错）并发，且集中在近 24 小时新报问题。
- 重点主题：Norm/Reduction 正确性、ONNX/FakeTensor 兼容性、Higher-order ops（`map`/`while_loop`）编译稳定性、CUDA/Triton 代码生成与运行时异常。
- 另一个信号是 CI 稳定性与性能：存在 inductor flaky test disable，以及 Grid2D 引入的性能回退讨论。
- 存在高优先级/静默正确性项：`#181696`（高优先级标签）及 `#183249/#183120/#183082/#182965` 等 silent correctness 风险。

## 重点关注

- **[#181696 Eval-mode `BatchNorm`/`GroupNorm` produces wrong output under `torch.compile(backend='inductor')`](https://github.com/pytorch/pytorch/issues/181696)**  
  关注原因: 已有 `high priority` + `correctness (silent)` 标签，且评论指出可在非 Inductor 路径复现，可能涉及更上游分解/dispatcher。  
  建议动作: 先按 `aot_eager_decomp_partition` 与 Inductor 分层复现，明确 owner（decompositions vs dispatcher vs inductor）并加阻断回归测试。
- **[#182965 `torch.compile` silently returns a result for `torch.linalg.cholesky` on non-positive-definite input](https://github.com/pytorch/pytorch/issues/182965)**  
  关注原因: 错误检查语义偏差（eager 抛错，compile 不抛），属于静默错误且影响线代核心算子可信度。  
  建议动作: 对齐 eager 的异常路径，优先补 error-checking lowering/guard，并增加 PD 输入单测。
- **[#183249 `torch.compile` produces wrong results for `fractional_max_pool2d` when `_random_samples` is not provided](https://github.com/pytorch/pytorch/issues/183249)**  
  关注原因: `module: correctness (silent)` + `module: random`，随机路径默认触发时易误导用户结果。  
  建议动作: 先确认 `_random_samples` 默认分支的 eager/compile 语义差异，短期给出明确 workaround，长期修复随机采样 lowering。
- **[#183401 [inductor][cpu] ... CppCompileError ... nightly release](https://github.com/pytorch/pytorch/issues/183401)**  
  关注原因: 已定位可疑 bad commit，影响 quantized_qat 模型与 nightly 信心。  
  建议动作: 基于给定 commit 做快速 bisect/partial revert 验证，并补 CPU CPP wrapper 回归集。
- **[#155679 Torch compile CUDA graphs leads to a large number of CUDA streams](https://github.com/pytorch/pytorch/issues/155679)**  
  关注原因: 维护者确认 13.2 仅部分修复，仍有剩余 root cause；涉及 distributed all_reduce + CUDA graphs 性能与资源风险。  
  建议动作: 跟进剩余修复 PR 和 stream 生命周期验证（是否随执行回收），补 profiler 回归基线。
