# PyTorch Compiler Issue Digest - 2026-06-28

## 今日概览

- 今日匹配 5 个 issue，全部为 open，closed 为 0。
- 主要风险信号是 Inductor cache / dynamic shapes / CPU lowering 相关 crash，尤其是分布式 all-gather warm FX graph cache 可能跨 rank 复用错误代码。
- 主题集中在 Inductor distributed cache、CPU dynamic shapes convolution lowering、AArch64 benchmark regression、Dynamo CUDA Event/Stream 类型建模，以及 FlexAttention compile UX。
- 有高优先级 crash 项；未看到明确 silent-correctness 证据。

## 重点关注

- [#188332 Inductor: allgather fusion creates rank-specific cache that crashes when loaded by other ranks](https://github.com/pytorch/pytorch/issues/188332)
  - 关注原因: shared FX graph cache 可能让不同 rank 载入 rank/device-specific generated wrapper，二次 warm-cache 运行直接 crash。
  - 建议动作: 用两 GPU 复现，检查 bucketed all-gather lowering 的 cache key 是否需要纳入 rank/device/packing offset，或临时禁用相关 FX cache 路径。

- [#188323 [Inductor][CPU] dynamic=True convolution lowering crashes with ValueError: Exponent must be non-negative](https://github.com/pytorch/pytorch/issues/188323)
  - 关注原因: `torch.compile(backend="inductor", dynamic=True)` 在 CPU convolution lowering 中触发 SymPy shape evaluation crash，repro 和 traceback 较具体。
  - 建议动作: 在 current main 上复现并最小化 symbolic shape 表达式，补 CPU Inductor dynamic-shapes regression test。

- [#188336 AArch64 CPU - Inductor benchmark Regressions](https://github.com/pytorch/pytorch/issues/188336)
  - 关注原因: OSDC ARC arm64 runner migration 后 Compiler Inductor benchmark 绝对耗时变差，但证据也提示 eager path 可能同样变慢。
  - 建议动作: 对比 old/new runner 上 eager 与 Inductor absolute time，先区分 infra regression 和 compiler regression。

### #188332 Inductor: allgather fusion creates rank-specific cache that crashes when loaded by other ranks

- 链接: https://github.com/pytorch/pytorch/issues/188332
- 状态: open; 更新时间: 2026-06-27T11:36:37Z; 关键词: inductor
- 标签: 无
- 摘要: bucketed all-gather lowering 生成 rank-specific wrapper，但 shared FX graph cache 可能跨 rank 复用，导致 warm-cache crash。
- 领域: distributed
- 类型: bug
- 影响: high，分布式 Inductor cache 复用错误会让多 GPU 二次运行失败。
- 关键信号: repro 要求两 GPU、连续两次 `torchrun --nproc-per-node 2`、固定 `TORCHINDUCTOR_CACHE_DIR`；报错包括 CUDA driver invalid argument 或 Triton pointer access error。
- 建议跟进: 复现并审计 all-gather fusion wrapper 的 cache key，必要时加入 rank/device-specific 信息或禁用该路径缓存。

### #188325 torch._dynamo: EventVariable.python_type() returns torch.Event instead of type(self.value)

- 链接: https://github.com/pytorch/pytorch/issues/188325

- 标签: module: cuda, module: dynamo
- 摘要: `EventVariable.python_type()` 疑似 hard-code `torch.Event`，导致后续 `SuperVariable` MRO lookup 失败。
- 领域: Dynamo
- 类型: bug
- 影响: medium，影响 CUDA Event/Stream 相关 Dynamo 类型逻辑，但 repro 范围较窄。
- 关键信号: 最小 repro 调用 `SuperVariable(...)._resolved_getattr_and_source(..., "record")`；错误为 `ValueError: tuple.index(x): x not in tuple`；issue 也怀疑 `StreamVariable` 同类问题。
- 建议跟进: 审计 `EventVariable` / `StreamVariable.python_type()`，验证改为 `type(self.value)` 后补 Dynamo unit test。

### #188323 [Inductor][CPU] dynamic=True convolution lowering crashes with ValueError: Exponent must be non-negative

- 链接: https://github.com/pytorch/pytorch/issues/188323
- 状态: open; 更新时间: 2026-06-27T06:53:30Z; 关键词: inductor
- 标签: module: crash, module: cpu, module: convolution, module: dynamic shapes, module: inductor, oncall: cpu inductor
- 摘要: CPU 上 `torch.compile(backend="inductor", dynamic=True)` 编译特定 convolution bottleneck 时在 lowering 阶段 crash。
- 领域: Inductor
- 类型: bug
- 影响: high，CPU dynamic shapes + convolution 是核心路径，且 eager 正常、compiled dynamic 失败。
- 关键信号: 环境为 `torch: 2.14.0.dev20260624+cu130`、`cuda: 13.0`、device CPU；错误落在 `aten.convolution.default` 和 SymPy `Exponent must be non-negative`。
- 建议跟进: 在 main 上复现并收窄 shape expression，修正 symbolic shape simplification 或添加 graceful fallback。
