# PyTorch Compiler Issue Digest - 2026-07-05

## 今日概览

- 今日匹配到 3 个 issue，全部为 open，closed 为 0。
- 主要风险信号是 Windows 上 `torch/csrc/dynamo/compiled_autograd.h` 触发 MSVC `C2872: 'std': ambiguous symbol`，影响扩展编译，且两个 issue 指向同类问题。
- 主题集中在 Windows 编译失败、Compiled Autograd 头文件兼容性、以及 `torch.compile` 下 RMSNorm autocast 引发的 Inductor 性能/显存回退。

## Issue 分析

### #173232 error C2872: 'std': ambiguous symbol when compiling `csrc/dynamo/compiled_autograd.h`

- 链接: https://github.com/pytorch/pytorch/issues/173232
- 状态: open; 更新时间: 2026-07-05T03:28:25Z; 关键词: compile, dynamo
- 标签: module: windows, module: compiled autograd, oncall: pt2, triaged
- 摘要: Windows 上编译 CUDA/C++ extension 时，`compiled_autograd.h` 内 `std` 名称解析与 MSVC 头文件冲突导致 C2872。
- 领域: AOTAutograd
- 类型: bug
- 影响: high，最小 extension 包含 `torch/extension.h` 也可能构建失败。
- 关键信号: MSVC 14.42、CUDA 13.0、torch 2.11.0+cu128、Python 3.13、Windows 11；错误位于 `IValuePacker<__int64>` 实例化路径；近期评论称已验证修复，维护者同意接手。
- 建议跟进: 尽快提交/评审修复 PR，并添加 Windows 编译覆盖以防回归。

### #188955 rms_norm autocast fp32 policy (2.12) materializes standalone cast kernels under torch.compile when dtypes already match. Peak-memory and throughput regression for bf16 models

- 链接: https://github.com/pytorch/pytorch/issues/188955
- 状态: open; 更新时间: 2026-07-04T22:31:37Z; 关键词: compile
- 标签: module: performance, module: memory usage, module: regression, module: inductor, oncall: pt2
- 摘要: `rms_norm` 在 torch 2.12 autocast fp32 policy 下，即使 input/weight 已是 bf16，也会在 `torch.compile` 中产生额外 cast kernel 和显存开销。
- 领域: Inductor
- 类型: performance
- 影响: high，报告称会造成 peak-memory 和 throughput regression，尤其影响 bf16 大模型。
- 关键信号: 最小 repro 为 `Linear(4096, 4096)` + `RMSNorm(4096)`、bf16、compiled forward/backward；报告指出 standalone `triton_poi_fused__to_copy*` kernel 和 full-size fp32 activation buffer。
- 建议跟进: 先复现 benchmark，再评估将 `rms_norm` autocast policy 改为 promote 是否保持 #167308 语义并消除额外 cast。
