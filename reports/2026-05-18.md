# PyTorch Compiler Issue Digest - 2026-05-18

## 今日概览

- 今日匹配 `compile/inductor/dynamo` 标题的 issue 共 **26** 条（**open 10 / closed 16**）。
- 主要风险信号是 **silent correctness + backward crash**：多条 `torch.compile` 在梯度或复杂 dtype backward 上出现错误或崩溃。
- 重点主题集中在：`Inductor` 正确性回归、complex/stride 场景 backward 崩溃、小图 runtime overhead、以及部分历史问题“nightly 不可复现后关闭”。
- 存在高优先级/高风险项：`#184113`、`#182012`（silent correctness）和 `#184101/#184100/#184081/#184088/#184089`（crash 类）需持续跟进。

## 重点关注

- **#184113 [silent correctness] torch.compile catastrophically changes grad output of in-place autograd matmul**  
  关注原因: 训练梯度“明显错误”，且报告称跨 CUDA/CPU/MPS 可复现，属于高风险 silent correctness。  
  建议动作: 先要求最小可复现脚本固定版本与 seed，并由 Dynamo/Autograd owner 做 `AOTAutograd vs Inductor` 切分定位。

- **#182012 `torch.compile` silently produces all-zero `x.grad` for `diagonal_scatter(...).sum().backward()`**  
  关注原因: repro agent 在 nightly 3/3 复现，属于确定性梯度错误，且已有人在推进 PR。  
  建议动作: 跟踪修复 PR 合入与回归测试落地（覆盖 `diagonal_scatter` backward + Triton lowering 路径）。

- **#184101 `torch.compile` backward crashes for `abs()`/`angle()` on transposed complex tensors**  
  关注原因: complex + transpose + backward 崩溃，当前无评论确认修复状态。  
  建议动作: 补充最小 repro 的 stride 约束与失败栈，优先分派给 Inductor complex 路径维护者。

- **#184100 `torch.compile` backward crashes when complex tensor is multiplied by Python complex literal**  
  关注原因: 常见表达式触发 backward crash，影响 complex 工作负载可用性。  
  建议动作: 增加 decomposition/functionalization 对 Python complex literal 的覆盖测试并确认 workaround 成本。

- **#161783 torch.compile has runtime overhead on small graphs**  
  关注原因: 带 `high priority` 标签，且最新评论已关联 PR `#184133` 做 wrapper 微优化。  
  建议动作: 尽快量化 PR 前后延迟收益，确认是否覆盖主要 overhead，必要时继续剖析 AOTAutograd/runtime wrapper 热点。
