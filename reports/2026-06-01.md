# PyTorch Compiler Issue Digest - 2026-06-01

## 今日概览

- 今日标题命中 `compile/inductor/dynamo` 的 issue 共 **33** 条，其中 **open 7**、**closed 26**。
- 今日最强风险信号是 **open 的编译挂起/代码生成失败**（集中在 `torch.compile + torch.func.grad` 与 Inductor C++ codegen 路径）。
- 主要主题集中在：`torch.func.grad` 组合路径的 compile-time 异常放大、Inductor 生成非法 C++、以及错误检查语义与 eager 不一致。
- 存在明确的高优先级/silent-correctness 信号：`#182965`（open，silent correctness）；另有已关闭但近期仍有复现信号的 correctness 历史单（如 `#151918`、`#151309`），需要保守复核。
- 大量 closed issue 的最近证据是“repro agent 未复现即关闭”，修复链路在片段里并不总是完整，结论置信度不一。

## 重点关注

1. [#182965 `torch.compile` silently returns a result for `torch.linalg.cholesky` on non-positive-definite input](https://github.com/pytorch/pytorch/issues/182965)；关注原因：silent correctness 且 repro agent 在 H100 上 3/3 复现，eager/compile 语义分叉；建议动作：优先跟进提到的修复 PR 合入状态并补充错误传播回归测试。  
2. [#181653 torch.compile(torch.func.grad(fn)) hangs indefinitely on models with pooling ops — sympy.simplify exponential recursion in stride_at](https://github.com/pytorch/pytorch/issues/181653)；关注原因：open 且“无限挂起”直接阻断可用性，报告者称 nightly 仍复现；建议动作：对 `stride_at/sympy.simplify` 路径做 profile 与超时保护实验，产出最小符号表达式复现。  
3. [#181621 torch.compile (Inductor) generates invalid C++ kernel: tmp8 used outside its declared scope when torch.gather index is a self-referential expression](https://github.com/pytorch/pytorch/issues/181621)；关注原因：代码生成作用域错误导致 C++ 编译失败，属于确定性编译阻断；建议动作：在 C++ wrapper/kernel 生成阶段加作用域一致性检查并补 gather 回归用例。

5. [#181006 [inductor] fails at caching stage with UnboundLocalError (bufXX referenced before assignment) when compiling torch.func.grad with MultiheadAttention + LayerNorm](https://github.com/pytorch/pytorch/issues/181006)；关注原因：open crash，`torch.func.grad` + Inductor 缓存路径稳定报错；建议动作：复跑给定 gist 并抓取缓存阶段 IR，定位未初始化 buffer 的生成路径。
