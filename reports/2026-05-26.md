## 重点关注

- #182190 [Non-blocking DtH/HtD not ordered properly under compile](https://github.com/pytorch/pytorch/issues/182190)

  建议动作: 跟进负责人方案（event-based ordering）并要求附最小回归测试（non_blocking copy + `.item()`/`.tolist()`）。

  关注原因: CPU Inductor 布尔归约索引错误，属于 silent correctness，且已有修复 PR `#185157`。  
  建议动作: 优先 review/merge PR，并补充 CPU/CUDA 对齐测试覆盖 bool argmin/argmax。

- #185185 [torch.compile(fullgraph=True) fails with PendingUnbackedSymbolNotFound when tensor-derived scalar values are used as slice bounds](https://github.com/pytorch/pytorch/issues/185185)  
  关注原因: 新开 open，repro 指向 Dynamo symbolic-shape 路径，尚无评论验证。  
  建议动作: 先复现并最小化到纯 Dynamo case，确认是否与 unbacked symbol handling 回归相关。

- #185135 [[inductor] Scheduler phases scale poorly on lowered aten.lstm/aten.gru graphs](https://github.com/pytorch/pytorch/issues/185135)  
  关注原因: compile-time 性能劣化量化明确（多层 LSTM 可达 80s+）。  
  建议动作: 建立 scheduler phase profiling 基线并拆分优化任务（GraphLowering/Scheduler/pattern pass）。
