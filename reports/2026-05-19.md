# PyTorch Compiler Issue Digest - 2026-05-19

## 今日概览

- 今日命中标题关键词（compile/inductor/dynamo）的 issue 共 **82** 条，其中 **open 55**、**closed 27**。
- 主要风险信号集中在“正确性与稳定性”：open 状态中有 **4** 条 `module: correctness (silent)`、**9** 条 `module: crash`、**3** 条 `module: regression`，且不少带可复现信息。
- 主题上，**Inductor** 相关最密集（`module: inductor` 67 条），其次是 Dynamo 路径与编译行为一致性问题。
- 今日较突出的子主题包括：索引/shape 检查缺失导致的 silent wrong result、卷积/stride 预测相关编译崩溃、以及 CUDAGraph/process pool 清理与生命周期问题。
- 存在高优先级/静默正确性风险，需要优先看护；但部分条目仍是“复现信息有限”或“已关闭待核对关闭原因”。

## 重点关注

- [#184113 [dynamo][autograd.Function] torch.compile catastrophically changes grad output of in-place autograd matmul](https://github.com/pytorch/pytorch/issues/184113)
  - 关注原因: 带 `high priority` + `module: correctness (silent)`，且描述为梯度“catastrophically changes”，属于潜在 silent-correctness 核心风险。
  - 建议动作: 先锁定最小可复现与受影响版本区间，补充 CI 回归测试并评估是否需要临时 guard/降级。
- [#184247 [Inductor] Incorrect epilogue fusion for user-defined Triton kernels when output has layout-changing ops (`.T.contiguous()`)](https://github.com/pytorch/pytorch/issues/184247)
  - 关注原因: `module: correctness (silent)` 且 repro agent 报告可稳定复现（数值差异与大面积 mismatch）。
  - 建议动作: 对 epilogue fusion 增加 layout 约束检查，先用回归测试覆盖 `.T.contiguous()` 这类写索引重映射路径。
- [#184272 PyTorch 2.12 compile error: Boolean literal getting used as LHS expression](https://github.com/pytorch/pytorch/issues/184272)
  - 关注原因: 新近回归信号（`module: regression` + `module: dynamo`），生成代码出现明显非法语法片段。
  - 建议动作: 立即做版本 bisect 并关联最近 codegen 变更，优先确认是否影响 2.12 release 用户面。
- [#183986 `torch.compile` silently produces wrong results for `index_add`/`index_copy`/`index_fill`/`index_put` on expanded (stride-0) tensors](https://github.com/pytorch/pytorch/issues/183986)
  - 关注原因: 明确 silent wrong result，且涉及常见 indexing 家族算子，潜在影响面较广。
  - 建议动作: 在 inductor 索引/stride-0 路径加一致性断言，短期提供可控 fallback 或禁用相关融合。
- [#183769 torch.compile skips out-of-range check for torch.select and returns invalid values](https://github.com/pytorch/pytorch/issues/183769)
  - 关注原因: eager 抛错而 compiled 返回“无效值”，属于行为语义偏离并可能污染下游计算。
  - 建议动作: 优先补齐 error-checking 语义对齐测试（eager vs compiled），并跟进提及中的修复 PR。
